# Fosti company profile
Repository ini Merupakan website resmi untuk FOSTI UMS.

---
## instalasi
### 1. Prasyarat

Pastikan sudah menginstall:
- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/installation)

### 2. Clone Repository
```bash
git clone https://github.com/AhmaddAssegaff/fosti-company-profile.git
cd fosti-company-profile
```

### 2. Install dependencies & running project
```bash
pnpm i 
pnpm run dev
```

---

## Tech Stack
Stack yang di gunakan yaitu [T3 Stack](https://create.t3.gg/)

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
